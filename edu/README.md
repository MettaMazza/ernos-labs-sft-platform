# Smithian Fold Theory Open Education Library

This directory is the working home for an open-source educational library built
from Smithian Fold Theory (SFT), beginning with the foundational theorem and
progressing from early learning to advanced independent reconstruction.

## Governing principle

SFT is the content authority. External curricula, textbooks, scientific models
and measurements may be used only to:

- calibrate age, reading load and assessment style;
- name a question or comparison surface;
- distinguish SFT from a conventional account; or
- test an already derived SFT consequence through the repository's lawful
  post-seal empirical route.

They may not supply a premise, select a law, fill a derivational gap or be
presented as SFT authority.

- [`COMPANION_GAME_STANDARD.md`](COMPANION_GAME_STANDARD.md) — the reading-first

The first working companion is
`edu/games/companion-adventures/`, paired with E01 review version 1.3.0. Its
Level One is one continuous original 3D story-puzzle adventure. Its hidden book
codes unlock optional story moments only. The game teaches the full child-facing
lesson; the book remains a distinct, slower challenge/reveal reading route with
deeper shared discussion.
