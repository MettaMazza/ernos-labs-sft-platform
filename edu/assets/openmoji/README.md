# OpenMoji assets used by the Early Years books

The colour SVG files in `16.0.0/color/svg/` are copied unchanged from OpenMoji
version 16.0.0, already installed in the companion-game dependency tree.

OpenMoji is created by the OpenMoji project and contributors and is licensed under

- Project: https://openmoji.org/

- Source package: https://www.npmjs.com/package/openmoji

These stable local copies let every book render the same recognisable repeated
learning object without depending on a device’s emoji font or on a network request.
The OpenMoji-derived images remain CC BY-SA 4.0. The educational text, original
character/world illustrations and other project material retain their separately
stated licences.
