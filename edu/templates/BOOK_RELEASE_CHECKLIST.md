# SFT Educational Book Release Checklist

## Scientific fidelity

- [ ] Live repository checkpoint reconstructed from receipts and censuses.
- [ ] Every scientific statement maps to an admitted claim or is marked `OPEN`.
- [ ] Dependency order is valid.
- [ ] Provenance labels are correct.
- [ ] WHY, DERIVATION and CHECK remain distinct.
- [ ] Rejected alternatives and adverse evidence are retained at the suitable
      learner level.
- [ ] External material does not enter derivation.
- [ ] Scientific status and boundary wording match the current receipt.
- [ ] Protected engine and verification-authority seals pass.

## Educational quality

- [ ] Audience, prerequisites and learning outcomes are explicit.
- [ ] Vocabulary and sentence load suit the stage.
- [ ] Examples progress from supported to independent.
- [ ] Retrieval, reasoning, transfer and misconception checks are present.
- [ ] Answers explain reasoning rather than list results.
- [ ] Teacher/adult guidance is complete.
- [ ] Curriculum navigation is labelled reference-only.

## Accessibility and safeguarding

- [ ] Semantic accessible edition exists.
- [ ] Every meaningful image has an equivalent text description.
- [ ] Colour is not the only information carrier.
- [ ] Contrast, type size, spacing and page density pass visual review.
- [ ] Activities include supervision, material and risk guidance.
- [ ] High-stakes medical, human-participant and ethical boundaries are clear.

## Publishing integrity

- [ ] Manifest validates against the schema.
- [ ] Version and live-work status appear in all artifacts.
- [ ] Author and licence are correct.
- [ ] Changelog and source boundary are complete.
- [ ] PDF text extraction passes.
- [ ] Every PDF page has been rendered and visually inspected.
- [ ] Release checksums are recorded.
- [ ] Superseded editions are preserved.
- [ ] Scoped commit contains no unrelated user work.
- [ ] GitHub push has explicit authority.
- [ ] No DOI, Zenodo or other remote action occurred without separate approval.

## Final education-publication approval

- [ ] The exact version has been explicitly approved by Maria Smith.
- [ ] Any approval-requested changes were applied before the final gates ran.
- [ ] The manifest records the approval decision, approver and approval date.
- [ ] The final PDFs are checksum-identical to the approved rendered copies.
- [ ] The complete approved package is under
      `publications/education/current/<book-id>/<version>/`.
- [ ] Any earlier approved edition is preserved under
      `publications/education/superseded/<book-id>/<version>/`.
- [ ] The working source remains under `edu/` for future updated editions.
