# E03 review 2.0.0

Prepared: 1 August 2026
Status: complete GitHub review edition; not finally approved

This release replaces the former screen-like companion-book layout with a complete 32-page paper-native picture book for ages 3–5.

## What changed

- Rebuilt the story around one clear mission: discover the turning-light rule and mend the path to the Sunrise Arch.
- Preserved the moon–sun–moon teaser from the end of E02.
- Kept Mia, Sol and Tavi as the permanent trio and introduced Vee as the sole E03 guest.
- Added ten actual paper activities with later-page answers where appropriate.
- Introduced *side*, *turn*, *return*, *pattern*, *break* and *repair* only after visible experience.
- Kept Sol’s first try and all three route attempts visible for comparison.
- Replaced every repeated teaching item with stable OpenMoji assets.
- Added a complete adult guide, semantic HTML edition, exact claim map and full visual/accessibility audit.
