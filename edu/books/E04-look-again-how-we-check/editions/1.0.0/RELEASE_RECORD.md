# E04 review 1.0.0

Prepared: 31 July 2026

Status: working review; not finally approved

This review contains the 32-page student book *Look Again: How We Check*, its
adult guide, semantic HTML, exact claim-and-receipt map, licence record and
reproducible vector render source. It begins at the E03 garden gate and keeps
one Garden Welcome Sign mission through all nine learning stages.

The child meets Ivo, observes a four-picture source, builds it, covers and
rebuilds it, keeps the failed first rebuild, finds two differences, follows the
ordered placement trace, measures width and height as separate questions, asks
Ivo to reconstruct through a fresh path and resolves a disagreement by doing
the missing check. Each question is separated from its labelled answer page.

The student PDF is rendered as 32 square pages. Every page includes its words
above a recognisable vector sign, picture, tool, trace or checkpoint diagram.
The adult guide PDF preserves its complete headings, lists and canonical
narrator explanation. The accessible edition presents all 32 pages in source
order and exposes each picture description beside the matching text.

The checked-in verifier validates the canonical page sequence, nine
challenge/reveal pairs, exactly one new guest, fixed sign mapping, preserved
failed attempt, reading-code safety, receipt identities, accessible structure
and PDF page counts. It also rejects unexplained title drift, answer leakage,
missing measurement boundaries and unsafe final-publication status.

Companion Level Four remains a separate end-to-end implementation and review
gate. Its status must not be inferred from this book package.

This is a GitHub review version under `edu`. It must not be copied into
`publications/education` until Maria Smith explicitly approves this exact book
after reviewing it alongside the completed Level Four game.
