# Plain-language rules for child-facing text

These rules apply to every student book, caption, game prompt and spoken line.

1. Use the ordinary name first: **door**, **letter box**, **note**, **box**.
2. Add a detail only when the child needs it to see, choose or do something.
3. Say who did what, in the order it happened.
4. Do not make an object sound magical unless the story shows the magic.
5. Use short spoken sentences. Prefer one idea in each sentence.
6. Explain a new word with a visible example before using it alone.
7. Keep scientific or technical wording in the adult guide unless the lesson
   requires the child to learn that exact term.
8. Read every line aloud. If an adult would not naturally say it to a child,
   rewrite it.

Examples:

- Use “A note came through the letter box.”
- Do not use “A folded note slid through the brass rectangular slot.”
- Use “The door opened.”
- Do not use “The great brass door woke with a clunk.”
