# E01 - Something Is Here

**Shelf:** Early Years / Foundation
**SFT branch:** Foundation
**Scientific source:** `SFT-ROOT-THERE-IS-NO-NOTHING`
**Current edition:** 1.0.0 live

`Something Is Here` is the first book in the SFT Open Education Library. It is
a 24-page read-aloud picture and activity book for children roughly aged 3-5,
with an adult guide that preserves the exact operational boundary of the root
theorem.

## Package contents

- `source/book.json` - canonical page text, art direction and image descriptions.
- `source/render_e01.py` - reproducible PDF and semantic HTML generator.
- `adult-guide.md` - learning guidance, page prompts, activities and answers.
- `claim-map.json` - page-to-claim and provenance map.
- `book-manifest.json` - version, source boundary, licence and checks.
- `accessible/student-book.html` - semantic accessible edition (generated).
- `CHANGELOG.md` - preserved edition history.

Rendered PDFs are written to
`output/pdf/edu/SFT-EDU-E01-SOMETHING-IS-HERE/1.0.0/`.

## Scientific boundary

The book teaches only this operational result: an unpresented absence supplies
no counterexample, while every presented example is an occurrence and
therefore is not nothing. It does not claim knowledge of an unexpressed
metaphysical domain.
