# E01 - Something Is Here

**Shelf:** Early Years / Foundation
**SFT branch:** Foundation
**Scientific source:** `SFT-ROOT-THERE-IS-NO-NOTHING`
**Current working edition:** 1.1.0 review
**Final-publication approval:** pending Maria Smith's decision

`Something Is Here` begins the SFT Open Education Library. Version 1.1.0 is a
32-page discovery-led game story in which children help Mira and Pip complete
the Nothing Hunt. Eleven challenge/reveal routes let a child look, listen,
choose and reason before seeing the story's answer.

## Current package

- `source/book-v1.1.0.json` - canonical 32-page text, game flow, art directions
  and page-specific image descriptions.
- `source/render_e01_v1_1.py` - reproducible PDF and semantic HTML generator.
- `adult-guide.md` - exact source, facilitation, complete page answers,
  misconceptions, accessibility and safeguarding.
- `claim-map.json` - page-to-claim, provenance and challenge/reveal mapping.
- `book-manifest.json` - version, boundary, licence, artifacts and checks.
- `accessible/student-book-v1.1.0.html` - generated semantic edition.
- `CHANGELOG.md` - preserved educational history.
- `editions/1.0.0/RELEASE_RECORD.md` - immutable identity of the earlier
  working edition.

Rendered review PDFs are written to
`output/pdf/edu/SFT-EDU-E01-SOMETHING-IS-HERE/1.1.0/`.

## Scientific boundary

The book teaches only the independently replicated operational root claim. An
unpresented absence supplies no counterexample, while every presented example
is an occurrence and therefore is not nothing. The story does not claim
knowledge of an unexpressed metaphysical domain, add a numerical zero or create
an empirical result.

## Approval boundary

The edition may be reviewed from `edu/` and GitHub, but it must not enter
