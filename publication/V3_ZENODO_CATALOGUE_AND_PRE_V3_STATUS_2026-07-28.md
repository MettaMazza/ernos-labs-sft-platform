# Smithian Fold Theory V3 Zenodo catalogue and pre-V3 status

Status date: 28 July 2026

The authoritative V3 clean-room publication set contains the sixteen papers
listed below.  Every other Ernos Labs record on Maria Smith's Zenodo catalogue
has been marked with the exact public label
`[Depreciated and replaced by V3]`.

The operation did not delete or replace historical evidence.  It preserved
every original DOI, concept DOI, published version string and file, added a
leading status notice, and linked each historical record to its relevant V3
successor paper or papers.  Application records also state explicitly that the
application-specific V3 rebuild has not yet been published.

## Public verification result

version records: 38 versions within the sixteen V3 concepts and 121 versions
within the twenty-four pre-V3 concepts.  All 121 pre-V3 records carry the exact
status label.  No V3 record carries it.  The repeatable metadata tool is
`tools/mark_pre_v3_zenodo_records.py`; rerunning it is idempotent.
