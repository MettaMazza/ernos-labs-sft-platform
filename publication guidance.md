# Final Publication Pass — All SFT V3 Branch Papers

Perform a complete, publication-grade editorial, formatting, consistency and
proofreading pass across every finalised Smithian Fold Theory V3 branch paper.

This is a controlled editorial revision, not a scientific rewrite.

The repository's current papers, derivations, machine packages, evidence
records, manifests, source captures, tests and finalised field-wide knowledge
trees are the authoritative context. Read and assess their current state
directly. Do not rely on prior summaries, earlier versions, remembered claim
status or assumptions about what has or has not since been validated.

The objective is to make every paper:

1. publication-ready;
2. readable by unfamiliar specialists;
3. consistent across the complete corpus;
4. less mechanically repetitive;
5. grammatically and typographically clean;
6. faithful to the current scientific and machine records; and
7. ready for Maria Smith's final approval.

## 1. Authoritative context

Treat the current repository state as authoritative.

Before editing:

- read every finalised branch paper completely;
- read the current field-wide knowledge trees;
- inspect the current claim packages;
- inspect the current source and evidence manifests;
- inspect the current machine receipts;
- inspect the current reconciliation records;
- inspect the current verification reports;

- identify superseded drafts and do not use them as authority.

Do not assume that a claim remains adverse, unresolved, open, confirmed,
corrected or unvalidated because an earlier version said so.

Determine every current status from the present repository evidence.

Do not import status from previous conversations, summaries, comments, draft
prose or historical reports unless the current authoritative records preserve
it.

## 3. Scientific change control

Do not revise scientific content merely because it is unconventional.

Do not import external equations, assumptions, taxonomies, constants, models
or consensus positions to normalise the work.

Do not weaken or strengthen a claim without current repository evidence.

Do not reconcile apparent contradictions by prose alone.

Do not silently harmonise conflicting records.

When two authoritative records disagree:

- identify the disagreement;
- determine whether one is explicitly superseded;
- trace both to their source files;
- inspect the current machine and evidence records;
- correct only when the authoritative direction is unambiguous; and
- otherwise preserve the discrepancy and report it.

Editorial changes may improve expression, order, formatting and readability.
They may not manufacture scientific agreement.
