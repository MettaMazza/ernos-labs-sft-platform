# Approved SFT educational publications

This directory contains only educational book versions explicitly approved by
Maria Smith as final publications.

## Layout

- `current/<book-id>/<version>/` contains the complete current approved
  publication package.
- `superseded/<book-id>/<version>/` preserves every earlier approved package
  after a newer version is approved.

Working sources and review editions remain under `edu/` and `output/pdf/edu/`.
A GitHub push from those working locations does not by itself mean that Maria
Smith approved the book as a final publication.

Before copying a version into `current/`, the exact updated final copy must pass
all scientific, educational, accessibility, rendering and checksum checks. Its
manifest must record the approval decision, approver and approval date. No
approved package may be silently overwritten.
