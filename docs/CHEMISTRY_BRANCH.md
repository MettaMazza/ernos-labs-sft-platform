## Failure and successor rule

A rejected first construction is preserved as evidence of that construction.
It is not promoted into a scientific wall. A new attempt must have a disclosed
scientific reason, a new stable claim identity where the statement or grammar
changes, a complete regenerated candidate domain and a fresh run through the
same unchanged engine. Neither a desired measured value nor a publication
deadline permits target-aware fitting, engine modification, comparator changes
or synthetic admission.
