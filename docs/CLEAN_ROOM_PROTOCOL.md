# Third clean-room protocol

## Objective

V3 must independently reconstruct the complete SFT corpus in new Python source,
new enumerators and new certificates while preserving the earlier corpora as
mandatory observational and reconciliation evidence.

## Permitted starting authority

The clean room begins with:

- Maria Smith's self-proven foundational theorem;
- the constraints stated in `CONSTITUTION.md`;
- ordinary host-language and operating-system mechanics, quarantined from SFT
  mathematical meaning; and
- registered empirical observations when a natural-science programme explicitly
  requires observational derivation.

It begins with the complete registered statements, values, scopes and
falsifiers of earlier SFT work as observational reconstruction targets. It does
not execute or import earlier generated implementations, certificates or
answer tables as proof inputs, and applications cannot select laws.

## Separation model

Earlier work is represented in `prior-work-ledger/` by identity, location and
hash. The v3 derivation runner has no dependency path into that directory.

For each legacy claim:

1. register the earlier question, stated answer or value, exact scope, branch
   and falsification surface as a prior observation;
2. classify it as a mandatory V3 reconstruction obligation;
3. prevent the answer-bearing artifact from entering the derivation runtime,
   dependency manifest, candidate generator, eliminator or survivor selector;
4. generate the v3 candidate grammar;
5. execute its complete declared census;
6. derive and seal the v3 result;
7. execute adverse controls and independent certification;
8. compare the sealed V3 result with the already registered prior observation;
   and
9. record agreement, equivalence, stronger closure, weaker closure or
   discrepancy.

Human participants cannot erase their memory of earlier work, and V3 must not
pretend that valid prior results are unknown. Clean-room independence is
therefore established operationally: complete prior-observation registration;
no prior answer artifact in executable derivation; independently generated
candidates; source-bound execution; and post-seal result comparison.

## Protected boundaries

Automated checks must reject:

- dependencies from `sft/` into `prior-work-ledger/`;
- dependencies from `sft/` into `correspondence/`;
- dependencies from derivation into `experiments/post_seal_measurements/`;
- dependencies from a fundamental branch into `applications/`; and
- generated certificates that simply embed a registered expected answer.

Automated branch-publication checks must additionally reject:

- an earlier SFT result without a branch and V3 disposition;
- a branch called complete while a prior observation assigned to it is
  unmapped, unresolved or present only in a downstream branch paper;
- a measured relation presented as a forced absolute value; and
- a V3 result used downstream before its categorically owning branch records
  it in the current manuscript inventory.

## Discrepancy rule

A mismatch with an earlier corpus is evidence. It is preserved, registered and
investigated. V3 may change only for a newly demonstrated scientific reason, not
to imitate the previous result.

## Publication boundary

The local repository may be built and tested without publication. Creating a
remote, changing preserved repositories, marking papers superseded in their
public records, pushing code or publishing a DOI requires explicit authorization.
