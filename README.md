# Ernos Labs — Smithian Fold Theory Open Science Platform and Knowledge Tree

## One theorem. No fitted parameters. Every admitted result must survive the machine.

This repository is the accessible Python clean-room reconstruction of Smithian
Fold Theory: an open scientific knowledge tree intended to derive, enumerate,
test and, where the evidence demands it, reject claims across mathematics,
computation and the natural sciences.

An SFT claim is not admitted because it is familiar, persuasive or close to a
measurement. The candidate space must be generated from the Fold structure;
exactly one form must survive; every dependency must trace to the premise-free
foundational theorem; the arithmetic must obey the constitutional domain; an
implementation-distinct validator must reproduce the result; and an empirical
claim must be sealed before authoritative target data are opened. Any violation
halts admission.

## Current scientific correction

The published branch papers are preserved as immutable, citable v1 artifacts,
but their designation as complete current V3 branches has been withdrawn. A
full audit found that the original paper gate proved coverage of each paper's
own frozen inventory without also proving that the inventory contained every
relevant V1/V2 result.

The correction is substantive and remains the gate for branches after
Foundation:

- V1 registers 356 results; 339 still lack explicit V3 mapping and 344 lack
  same-strength closure after the Foundation reconciliation.
- V2 registers 407 numbered results; 281 still lack explicit V3 mapping and
  395 lack same-strength closure after the Foundation reconciliation.
- the Physics v1 paper documents 140 Physics claims while the live corpus now
  contains 160;
- physical constants, including inverse fine structure, must receive their
  complete derivation and empirical treatment in Physics before a downstream
  Chemistry paper consumes them; and
- no successor paper can be published until all 763 prior entries have been
  reviewed against that branch, every branch-owned component has exactly one
  categorical owner, and every obligation owned by that branch is closed at the
  strongest registered scope. The global all-branch owner ledger remains a
  separate final-TOE requirement.

Read the complete
[`published-branch completeness audit`](audits/PUBLISHED_BRANCH_COMPLETENESS_AUDIT_2026-07-24.md)
and the [`Physics prior-value audit`](audits/PHYSICS_PRIOR_VALUE_AUDIT_2026-07-24.md).

## Reproduce the current status

The portable baseline uses only the Python standard library on macOS, Windows
and Linux. No Docker container or heavy dependency is required.

```text
python3 tools/build_foundation_successor_bundle.py
python3 tools/verify_publication_compliance.py --branch foundation --require-ready
```

These commands validate the current Foundation successor without replaying
later branches that are deliberately being reconstructed in dependency order.
The all-branch replay becomes the release gate again when the sequential
successors have caught up. Closing Foundation does not waive the independent
audit and reconstruction required by Mathematics or any later branch.

## Method boundary

Earlier SFT work is mandatory observational authority: it determines the
questions and claimed values V3 must independently reconstruct. It is not
derivational authority: its executable code, certificates and answer-bearing
tables cannot enter the V3 derivation runtime or choose a survivor.

External consensus models likewise cannot select a law. Measurement becomes
admissible only after the exact SFT result has been generated and sealed. A
failed comparison is retained and blocks closure; it is never hidden by an
approximate resemblance or a historical label.
