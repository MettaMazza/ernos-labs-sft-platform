# Prior-work comparison ledger

This directory records the identity and hashes of preserved SFT repositories,
papers, releases and evidence bundles. It is not a derivational dependency.

It is, however, a mandatory reconciliation authority: every result the bound
V1/V2 record states as forced must be independently reconstructed to the full
V3 standard. “Prior work” or “historical” is never a completion disposition.
The old artifact cannot feed an answer into a new derivation, and the new model
cannot omit the old result by refusing to map it. Prior statements, values,
scopes and falsifiers are admissible observations and must be registered before
reconstruction; they select the obligation, never the V3 law.

The coordinated snapshot is expanded additively as lineage surfaces are found.
The prior result is openly registered in the observational census. Its
answer-bearing code, certificate or table may enter only the comparison
evaluator after the V3 result, controls and certificate are sealed. The V3
derivation runtime cannot read it.
