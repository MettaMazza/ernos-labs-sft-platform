Access to the catalogs and astronomical archives of the HEASARC

  • XAMIN

    The primary graphical user interface portal for exploring the data holdings, including catalogs and data products.
    Web Portal GUI Data access APIs

  • astroquery

    The astroquery.heasarc queries the main archive and astroquery.skyview queries SkyView imaging.

    astroquery.heasarc
    astroquery.skyview
    astroquery@HEASARC details

  • Catalogs

    Documentation for the roughly one thousand catalogs held at HEASARC. The mission "master" catalogs describe the observations and hundreds of scientific object catalogs can be used in a cross-match.

    Catalog Index New and Updated Catalogs

  • Skyview

    A powerful tool to visualize the sky with the largest collection of multiwavelength sky maps from the radio to the gamma-ray. This tool includes options for rebinning, interpolation, overplots, contours, etc.

    Details

  • Data in the Cloud

    HEASARC data are available in multiple places including the AWS cloud and the SciServer platform.

    Cloud Data

  • CMB Data

    Data from space-bourne and suborbital CMB experiments, as well as useful ancillary datasets.

    LAMBDA CMB Archive

Other Resources

  • Classic Browse - This legacy interface for querying the HEASARC database and downloading data products remains available, but we encourage you to try the modern portal.
  • Swift Data Query - A Browse interface customized for the Swift mission.
  • Other command line tools for data downloads - A download script can be useful, and we also have tips on using wget and curl.
  • Bibliography of HEASARC data sets with ADS-listed publications.
  • Documentation for the HEASARC Database System - General description of the database system and the TDAT format used to serialize data and metadata for HEASARC catalogs.
  • Open Archive Policy - Find out how you can integrate HEASARC resources into your website (to be updated).
