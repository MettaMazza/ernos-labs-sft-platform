Liquid-Liquid Equilibrium (LLE) Data Summary View (Ternaries)

Purposes & Features:

Ternary LLE data in TDE have one of two forms:

  • Binodal: phase boundary compositions, reported as PTx1'x2'
  • Tie Line: compositions of co-existing phases, reported as PTx1'x1''x2'x2''

Summarize LLE Data in one table: Both LLE data types are shown in a single table accessed through this node (see below). Tie-line data are represented as two data sets in TDE, as dictated by the Gibbs Phase Rule.

Identify Tie-line data sets: Tie-line data are highlighted in the table for easy identification (see below).

Plotting: A ternary phase diagram can be generated with both binodal and tie-line data indicated with separate symbols.
