# Chemistry external-source registry

Only official terminology, metrology and reference-data bodies are registered.
Snapshots are immutable comparison targets. Their content is unavailable to a
claim's prediction program until its Fold derivation has been sealed.

The IUPAC and CIAAW records define chemical identities, terminology and the
known periodic observation boundary. NIST supplies atomic, molecular,
spectroscopic, thermochemical and chemical-property records. None of these
sources is derivational authority and no value or conventional equation in a
snapshot may select a Fold law.
