# Scientific source tree

This package contains v3 scientific implementation only after a corresponding
claim is registered. Python is the accessible host; it is not a source of SFT
law.

Dependencies must move downward from foundation through later sciences. Source
in this tree cannot import prior-work answers, conventional correspondence,
post-seal measurements or application outputs.

The Lean 4 project in `generated/lean4_validation/` is deliberately outside
this scientific source tree. It reads the 2,765-claim current model and writes
only its own report; it does not modify `sft/`, replace the admission engine or
become a source of SFT law.
